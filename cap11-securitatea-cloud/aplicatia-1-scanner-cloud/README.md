# Aplicația practică 1: Scanner de configurări cloud (CloudScanner)

**În carte:** capitolul 11, „Aplicații practice”, Aplicația practică 1.

Verifică o configurație cloud simulată (stocare, IAM, rețea, criptare, jurnalizare) contra unui set de reguli și
produce un raport pe niveluri de severitate. **Cerințe:** .NET 10 SDK (Anexa A). **Rulare:** `dotnet run`. Începutul ieșirii este tipărit în carte.
